# Changelog

Notable changes to proto-kit. Format: [Keep a Changelog](https://keepachangelog.com/),
versions follow [semver](https://semver.org/).

## [Unreleased]

### Added
- `npm create proto-kit@latest`: one command to start a client project
  (`create/`, not published on npm yet).
- `npm run doctor`: checks the machine and says how to fix what is missing.
- `.mcp.json`: Figma desktop MCP server declared for the project.
- Docs: `docs/getting-started.md`, `docs/how-it-works.md`.
- Open source files: MIT licence, contributing guide, code of conduct, security
  policy, issue and pull request templates, Dependabot.

### Changed
- `BOOTSTRAP.md` moved to `docs/kit-brief.md`, marked as historical.

## [0.1.0] - 2026-11-09

### Added
- First version: 7-phase method in `CLAUDE.md`, 8 Claude Code skills, token
  linter, visual diff, accessibility audit, `example/` with `npm run selftest`,
  CI workflow.
